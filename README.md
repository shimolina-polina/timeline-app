# Timeline App

React + TypeScript проект с использованием Webpack для сборки.

---

## Инструкция по запуску

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/your-username/timeline-app.git
cd timeline-app
```

### 2. Установите зависимости

```bash
npm install
```

### 3. Запустите дев-сервер для разработки

```bash
npm run dev
```

Откроется браузер с приложением на [http://localhost:8080](http://localhost:8080) (или другом порту).

---

## Требования

* Node.js v14+
* npm v6+
